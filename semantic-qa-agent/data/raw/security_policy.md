# Information Security Policy

## Access Control

Access to production systems is granted on a least-privilege basis and is
reviewed quarterly. All access requests require approval from both the system
owner and the security team. Shared accounts are prohibited without exception.

## Data Classification

Information is classified as Public, Internal, Confidential, or Restricted.
Restricted data, which includes customer personal data and payment information,
may not be copied to personal devices or to any storage service that has not
been approved by the security team.

## Incident Reporting

Suspected security incidents must be reported to the security team within one
hour of discovery. This includes lost devices, suspected phishing, and any
accidental disclosure of Confidential or Restricted information. Reporting in
good faith will never result in disciplinary action.

## Device Standards

All company laptops must run full-disk encryption and the managed endpoint
agent. Devices that have not connected to the management server for 30 days are
automatically suspended from network access.
